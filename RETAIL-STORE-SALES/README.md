# Retail Sales Dashboard

![Dashboard Preview](https://github.com/AlhNobleman/Data-Analytics-Portfolio/blob/main/RETAIL-STORE-SALES/001_Retail_Store_Dashboard.png)

## 📋 Project Overview
End-to-end retail sales analysis using **Tableau** and **SQL**.  
Analyzed over 11,000 transactions to understand revenue trends, customer behavior, and product performance.

## 🎯 Key Insights
- Average Order Value = $129.7
- Total Revenue = $1.55 Million
- Top performing category: Butchers

## 🛠️ Tools & Skills Demonstrated
- **Tableau Public** – Dashboard creation, calculated fields, visualizations
- **SQL** – Data cleaning, aggregations, customer segmentation
- Data Analysis & Storytelling
