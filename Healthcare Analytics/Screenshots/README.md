# Dashboard Screenshots

This folder is reserved for images that make the Power BI project easy to review on GitHub.

Please export screenshots from Power BI Desktop and add:
- `dashboard-overview.png` — full dashboard overview.
- `patient-trends.png` — trend analysis.
- `filters-and-details.png` — key slicers or supporting visuals.

Use clear, readable images and remove or mask any personally identifiable or confidential patient information before committing files.
